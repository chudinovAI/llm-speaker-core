# Отдел расписания

Основными функциями отдела расписания являются составление расписания аудиторных занятий, государственных аттестационных испытаний государственной итоговой аттестации, экзаменационной сессии для всех форм обучения по ОП ВО в головном вузе

## Основные задачи

- Составление расписания аудиторных занятий, экзаменационных сессий для очной и очно-заочной (вечерней) формы обучения по ОП ВО.
- Составление расписания учебно-экзаменационной сессии для обучающихся заочной формы обучения по ОП ВО.
- Составление расписания государственных аттестационных испытаний государственной итоговой аттестации по ОП ВО и ОП СПО.
- Информационно-консультационное обеспечение кафедр и других структурных подразделений ГУАП по вопросам деятельности отдела.
- Осуществление функции диспетчеризации общеуниверситетского аудиторного фонда.
- Мониторинг и анализ эффективности использования аудиторного фонда.
- Мониторинг проведения учебного процесса в головном вузе, включающий в себя проверку соответствия расписания учебным планам, контроль за выполнением профессорско-преподавательским составом утвержденных расписаний.
